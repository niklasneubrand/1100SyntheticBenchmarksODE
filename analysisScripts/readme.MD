This folder contains all scripts to analyze the synthetic benchmark problems.
It is organized into:
* `benchmarkAnalysis`: analyses of problem characteristics, identifiability, and multistart optimization.
* `paperFiguresAndTables`: notebook and documentation for the paper figures and tables.
* `supplementary`: the notebook, scripts, data, and figures for the supplementary material.

To merge all results in one large feature table, apply the scripts from
`benchmarkAnalysis/mergeResultsTables`.
